## Purpose

The standard intake checklist for an individual tax return engagement. Every 1040 engagement starts with this checklist applied to the client's prior-year return + the current-year intake.

## Pre-engagement (Karbon Client Request template `1040-intake-v6`)

Send the following to the client by **January 31** for an April 15 filing:

- [ ] Signed engagement letter (current year)
- [ ] Updated personal info form (address, phone, marital status, dependents)
- [ ] Direct deposit authorization (if refunds expected)

## Income documents (request from client + cross-reference)

- [ ] All W-2s — match against prior-year employers; flag if any are missing
- [ ] 1099-NEC / 1099-MISC for self-employed income
- [ ] 1099-DIV, 1099-INT, 1099-B from all brokerage accounts
- [ ] 1099-R (retirement distributions) — IRA vs. employer plan
- [ ] SSA-1099 (Social Security)
- [ ] Schedule K-1s — see [Schedule K-1 Treatment Reference]
- [ ] 1099-G (state refunds, unemployment)
- [ ] 1099-S (real estate sales)
- [ ] Rental income summary (if Schedule E filer)
- [ ] Business income summary (if Schedule C filer)
- [ ] Foreign income statements (if FBAR/8938 territory)

## Deductions & credits

- [ ] Mortgage interest 1098s for all properties
- [ ] Property tax statements
- [ ] State & local tax payments (note SALT cap)
- [ ] Charitable contributions (cash + non-cash, both itemized)
- [ ] Medical expenses (only above AGI threshold)
- [ ] Childcare expenses + provider EIN/SSN
- [ ] Tuition statements (Form 1098-T)
- [ ] Student loan interest (Form 1098-E)
- [ ] HSA contributions and distributions (Form 5498-SA + 1099-SA)
- [ ] IRA contribution statements (Form 5498)

## Tax payments

- [ ] Federal estimated tax payments (quarterly amounts + dates)
- [ ] State estimated tax payments
- [ ] Prior-year overpayment applied

## Special situations to surface to manager BEFORE starting prep

- [ ] First-time client (prior-year return needed for comparison + carryforwards)
- [ ] Major life change (marriage, divorce, death of spouse, new dependent)
- [ ] Sale of primary residence (§121 exclusion analysis)
- [ ] Cryptocurrency activity (every disposition is a taxable event — request transaction-level detail; do not accept "I made some profit")
- [ ] Foreign account ownership (FBAR / Form 8938 thresholds)
- [ ] Trust or estate involvement (1041 K-1 received)
- [ ] State residency change during the year (part-year filing in multiple states)
- [ ] Equity comp activity (RSU vesting, ISO exercise, ESPP sale)
- [ ] Business formation or dissolution during the year

## Engagement timing

- **Intake complete** = all checked or explicitly waived in writing
- **In prep** = intake complete + assigned to a preparer
- **In review** = prep done + ready for Chris
- **Ready to sign** = review complete + client signature requested
- **E-filed** = transmitted and accepted

We do NOT start prep work until the intake is complete or the missing items are explicitly documented. Half-complete intakes cause rework that costs more than the wait. This is firm policy as of 2024-01-15.
