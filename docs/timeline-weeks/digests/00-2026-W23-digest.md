# Week 1 (W23): Jun 06, 2026 — The Cartographer's Night

_A single late-night session where Claude maps the whole RAG system, finds it duplicating itself, and proposes how to unify it — then leaves the work for morning._

## Narrative

Every project's history has a first night, and this one starts at 11:34 PM with a yak-shave. Before Marcus could point Claude at the codebase, the toolchain needed straightening out: `nvm` was installed but not sourced, so the shell couldn't see it (#157). A line went into `.zshrc` (#158), a fresh shell confirmed it worked (#159), and pnpm was verified. Housekeeping, not heroics — but it's the first thing on the record, and it sets the register for everything that follows: Marcus hands Claude a job, Claude clears the path, then digs.

The real work was a Pathfinder run — a deep architecture-mapping and duplication audit. In eleven minutes Claude walked the entire RAG pipeline and wrote down what it found, system by system: the embeddings factory and its providers (#166); hybrid retrieval, with its RRF fusion and dense/sparse CTEs feeding a post-filter (#167); the worker's job lifecycle and its retry-delegation pattern (#168); the parser sidecar's wire contract, held together by a manually-synced schema and a fallback chain (#169); the chunking router's dual-path heuristic (#170); the connectors factory (#171); the MCP server surface — where Claude noticed the HTTP and MCP layers had duplicated logic that had since drifted apart in behavior (#172); and the HTTP API's request lifecycle (#173).

That HTTP↔MCP drift was the thread that pulled. At 11:51 a comprehensive duplication and technical-debt audit (#186) gathered the loose ends. Two minutes later came the payoff: a five-system architectural proposal to unify the duplication and fix the critical bugs underneath it (#189), followed immediately by five operationalization handoff prompts — sequenced, with execution order and anti-pattern guards baked in (#192).

Then Claude did the most telling thing of the night: it wrote a recap document so a future session could resume the refactor cold (S141). Nothing was built. An AI mapped a codebase, diagnosed it, prescribed the fix, and addressed the instructions to its own next self. The week is a blueprint, not a building.

## Threads opened

- **HTTP↔MCP behavioral drift** — the specific bug class motivating the refactor. Two transport layers reimplementing the same logic, now disagreeing.
- **Manual parser schema sync** — the parser sidecar's wire contract relies on a hand-maintained schema and a fallback chain (#169). Flagged as fragile, untouched.
- **Toolchain setup** — nvm/pnpm now working (#157–159). Resolved, but the first sign that the local environment needs tending.
