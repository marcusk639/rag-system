# Known issues

This is the single backlog of open issues for rag-system. Each issue is one table row with one status. Every row was
re-checked against the code at commit `2b40404` on 2026-10-21; anything found fixed was left out, and git plus the
archived reviews under [`archive/reviews/`](archive/reviews/) hold the resolved history. IDs (`KI-<area>-<n>`) are
stable, so cite them from code, commits and other docs. Where a code comment or older doc cites a previous ID, that
ID appears as an alias in the Source column (for example "ISSUES P3"). Organisational compliance items (counsel, WISP,
vendor register, training) are not repeated here; they live in
[compliance/CONTROL-STATUS.md](compliance/CONTROL-STATUS.md#open-legal-and-process-items). Launch gates live in
[launch/LAUNCH-STATUS.md](launch/LAUNCH-STATUS.md).

**Status values.** `open`: nothing blocks the work. `decision-needed`: an owner call comes first (see
[Decisions needed](#decisions-needed)). `deferred: <unblocker>`: parked until the named condition holds.

**Source abbreviations.** QUALITY = `RAG-QUALITY-REVIEW-2026-10-17`; REVIEW = `RAG-REVIEW-2026-09-16`; CRITICAL =
`RAG-CRITICAL-REVIEW-2026-09-16`; ISSUES = `ISSUES-AND-OPTIMIZATIONS`; LAUNCH-REV = `LAUNCH-READINESS-REVIEW-2026-10-03`;
PRR = `PROTOTYPE-READINESS-REVIEW-2026-08-01`; LOCAL-LLM = `2026-10-02-local-llm-verification-REVIEW`; all under
[`archive/reviews/`](archive/reviews/). Other archived sources are named in full.
